一、修复的三个问题

问题 1 删除 Skill 后列表仍展示 / 报「Skill 不存在」 已修复
原因：handle_skill_delete：当 Skill 目录已被其它方式移除时，直接返回错误，前端不会从列表移除；且 send_to_recycle_bin 只支持 Windows PowerShell，在 WSL 服务端运行会抛异常导致删除中断。
修复：目录已不存在时返回 ok=True, already_removed=True，前端据此同步移除列表项；send_to_recycle_bin 改为优先 gio trash，其次 trash-put，最后本地回收目录兜底。
验证：test_delete_fix.py 通过：对真实存在与已移除的 Skill 均返回正确结果。
问题 2 执行报 401 且错误日志看不到原因 已修复
原因：handle_chat 仅用 except Exception 兜底，HTTP 401 的响应体被吞掉；服务未开启文件日志，控制台「日志」面板拿不到任何信息。
修复：新增文件日志 ~/.workbuddy/logs/agent-grocery-workshop.log；handle_chat 单独捕获 urllib.error.HTTPError，返回带 HTTP 状态码与响应体的详细错误，并把请求与错误写入日志。
验证：test_chat_401_log.py 通过：401 错误信息含状态码，且日志文件中可检索到 /api/chat HTTP 401。
问题 3 生成 Skill 失败：cannot access local variable 'gdir' 已修复
原因：_run_generation_job 中先构造 gen 字典（引用了 gdir），再调用 record_generation 给 gdir 赋值，导致在 gdir 赋值前被引用，抛出 UnboundLocalError；另外 fallback 模板把 \n 写成字面量换行符，生成的 SKILL.md 全挤在一行。
修复：调整顺序：先算 gdir 再构造 gen；_build_skill_markdown / _generate_skill_content 中改用真实换行符。
验证：test_generate_5_skills.py 实际生成 5 个 Skill 全部成功，SKILL.md 换行正常。
